# Reference Templates — 디자인 레퍼런스

포트폴리오 **디자인** 레퍼런스 모음. 각 파일은 범용 슬라이드 10종을 실제처럼 채워 둔 완성형 슬라이드 덱이다. 특정 직무/프로젝트에 고정된 내용이 아니라 **디자인 무드(색·타이포·레이아웃)의 기준**으로 쓴다. 사용자의 실제 자료로 플레이스홀더를 채워 포트폴리오를 완성한다.

> 특수 슬라이드·포폴 디테일(도메인 특화 성과, 별난 레이아웃)은 레퍼런스에 심지 않는다. 그런 건 `../SKILL.md`의 프롬프트나 사용자 요청으로 **별도 제작**한다. 레퍼런스는 톤의 기준일 뿐.

## 슬라이드 미리보기 (side preview)

모든 레퍼런스는 브라우저로 열면 **옆에 슬라이드 썸네일 미리보기**가 뜨는 프레젠테이션으로 렌더된다. 채우기 전에 디자인을 눈으로 훑는 용도.

## 공통 플레이스홀더 규칙

- **`[대괄호]`** = 사용자가 반드시 바꾸는 값. 예: `[이름]`, `[회사명]`, `[github.com/username]`, `[프로젝트명]`.
- **샘플 문구·수치** = 톤을 보여주는 예시(예: `−78% 배치 실행 시간`). 반드시 실제 값으로 교체하고, 남기지 않는다.
- **이미지 자리** = 안내 라벨이 있는 카드(예: `아키텍처 다이어그램 · 16:9`). 실제 이미지로 교체한다. 안내 라벨은 `--guide-display` CSS 변수로 한 번에 끌 수 있다(`frosted-glass-teal`은 좌측 레일의 "가이드 숨기기" 버튼).
- **`data-speaker-notes`** = 각 `<section>` 슬라이드를 어떻게 채울지에 대한 지침(발표자 노트).
- **슬라이드 단위** = `<section>` 1개 = 1장. 프로젝트/항목 수에 맞춰 복제·삭제한다.

## 파일 형태 (편집 방법)

- `frosted-glass-teal.html` — **일반 HTML/CSS/JS**. 열어서 `<section>`을 직접 복제·수정. 자체 썸네일 레일 포함. 편집이 가장 쉽다.
- 나머지 4개 — **번들 아티팩트**(에셋·폰트 인라인). 실제 슬라이드 마크업은 `<script type="__bundler/template">`의 JSON 문자열 안에 있다. 편집 시 그 template을 추출해 수정한다. 디자인 톤 참고용으로는 브라우저로 그냥 열어 보면 된다.

## 새 템플릿 추가 시

이 표에 한 줄 등록(무드/톤 기준)하고, `../SKILL.md`의 자동 선택 규칙에도 반영한다. 새 디자인도 **같은 슬라이드 세트 + 위 플레이스홀더 규칙**을 공유하면 서로 갈아끼워 쓸 수 있다.
