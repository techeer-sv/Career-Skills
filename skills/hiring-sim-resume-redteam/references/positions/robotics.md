# Robotics Engineer — 시장 기대 역량 (엔진 D)

> 사용 규칙·공통 기준은 `../position-competency-map.md` 참조. 여기선 로보틱스 직군만.

**핵심 기대 역량**
- **ROS/ROS2**: 노드·토픽·서비스·액션 설계, DDS/QoS, launch·TF(좌표변환).
- **제어**: PID/MPC, 실시간 제어 루프(결정론), 상태 추정(Kalman/EKF).
- **인식(perception)**: 센서 퓨전(LiDAR/카메라/IMU), 캘리브레이션, 포인트클라우드.
- **SLAM·내비게이션**: 지도 작성·위치추정, 경로계획(path/motion planning, MoveIt/Nav2), 장애물 회피.
- **시뮬레이션**: Gazebo/Isaac Sim, **sim-to-real** 갭.
- **매니퓰레이션/모션**: 역기구학, 궤적 생성, 그리핑.
- **실시간·안전**: 안전 등급 제어, 비상정지, HW 통합·지연 관리.
- **(AI 접목)**: 강화학습·비전 기반 제어, 학습 정책의 안전.

**깊이 공백 신호**: 시뮬레이션만 있고 실기(real robot)·sim-to-real 없음 · ROS 노드 나열만, 제어/추정 수학 없음 · 센서 퓨전·캘리브레이션 부재.

**공백 시 후속질문**: "실제 로봇에 올렸나요, 시뮬만인가요? sim-to-real 갭은?" · "제어 주기와 지연은 어떻게 보장했나요?" · "센서 노이즈·캘리브레이션은?" · "경로계획에서 뭘 썼고 실패 케이스는?"
